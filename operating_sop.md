# Multi-Channel Catalog Operating SOP

1. Maintain one master SKU for every sellable item.
2. Keep source-of-truth product data separate from channel-specific overrides.
3. Document marketplace-specific titles, attributes, and exceptions.
4. Validate required fields before each bulk update.
5. Use a small test batch for high-risk catalog changes.
6. Review processing results and failed SKUs.
7. Verify live content after each update.
8. Keep a change log for repeatability and rollback.
9. Never store credentials or confidential client exports in public repositories.
